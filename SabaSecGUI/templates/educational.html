What is a Man-in-the-Middle Attack?

ما هو هجوم الرجل في المنتصف (MITM)؟
🇬🇧 English
A Man-in-the-Middle (MITM) attack happens when an attacker secretly inserts themselves between two communicating parties — intercepting, reading, and possibly altering the data flowing between them. The victims are completely unaware because the attacker silently relays traffic while eavesdropping.
🇸🇦 عربي هجوم الرجل في المنتصف (MITM) يحدث عندما يُدخل المهاجم نفسه بشكل خفي بين طرفين يتواصلان — فيعترض البيانات ويقرأها وربما يعدّلها. الضحايا لا يعلمون بذلك، لأن المهاجم يُمرّر حركة البيانات بصمت بينما يتجسس عليها.

ARP Spoofing — How It Works

تزوير ARP — كيف يعمل؟
🇬🇧 English
ARP (Address Resolution Protocol) maps IP addresses to MAC addresses on a local network. Because ARP has no authentication, any device can broadcast fake ARP replies claiming to own any IP address. The attacker exploits this to redirect traffic meant for the gateway through their own machine.
🇸🇦 عربي ARP (بروتوكول تحليل العناوين) يربط عناوين IP بعناوين MAC على الشبكة المحلية. لأن ARP لا يحتوي على مصادقة، أي جهاز يمكنه إرسال ردود ARP مزيفة يدّعي فيها امتلاك أي عنوان IP. يستغل المهاجم هذا لتحويل حركة المرور المخصصة للبوابة عبر جهازه.

SMTP Email Interception

اعتراض البريد الإلكتروني عبر SMTP
🇬🇧 English
SMTP (Simple Mail Transfer Protocol) sends emails over port 25/587 without encryption by default. Once an attacker performs ARP spoofing, they can intercept all email traffic — reading the sender, recipient, subject, and body, then modifying and forwarding the email to the real server undetected.
🇸🇦 عربي SMTP (بروتوكول نقل البريد البسيط) يرسل الإيميلات عبر المنفذ 25/587 بدون تشفير بشكل افتراضي. بمجرد أن يُنفّذ المهاجم تزوير ARP، يمكنه اعتراض كل حركة البريد — قراءة المرسِل، المستقبِل، الموضوع، والمحتوى، ثم تعديلها وإعادة توجيهها للخادم الحقيقي دون أن يُكتشف.

HTTP vs HTTPS — Encryption Matters

HTTP مقابل HTTPS — التشفير يهمّ
🇬🇧 English
HTTP sends data as plain text — anyone intercepting the traffic can read passwords, form inputs, and sensitive information. HTTPS encrypts the entire communication using TLS (Transport Layer Security), making intercepted packets completely unreadable without the private key.
🇸🇦 عربي HTTP يرسل البيانات كـنص واضح — أي شخص يعترض الحركة يمكنه قراءة كلمات المرور، مدخلات النماذج، والمعلومات الحساسة. HTTPS يُشفّر كامل الاتصال باستخدام TLS (أمان طبقة النقل)، مما يجعل الحزم المعترضة غير قابلة للقراءة تماماً بدون المفتاح الخاص.

How to Protect Yourself

كيف تحمي نفسك من هجمات MITM
🇬🇧 English
Understanding the attack is only half the battle. Real cybersecurity means knowing how to defend against these techniques. Below are the most effective countermeasures against MITM attacks — covering both technical and behavioral defenses.
🇸🇦 عربي فهم الهجوم هو نصف المعركة فقط. الأمن السيبراني الحقيقي يعني معرفة كيفية الدفاع ضد هذه التقنيات. فيما يلي أكثر التدابير المضادة فعالية ضد هجمات MITM — تشمل الدفاعات التقنية والسلوكية.
🔒
Always Use HTTPS
استخدم HTTPS دائماً
Look for the padlock icon. HTTPS encrypts all data between you and the server, making intercepted packets unreadable.
ابحث عن أيقونة القفل. HTTPS يُشفّر كل البيانات بينك وبين الخادم، مما يجعل الحزم المعترضة غير قابلة للقراءة.
🔐
Use a VPN
استخدم VPN
A Virtual Private Network encrypts your entire internet connection, protecting all traffic on public or untrusted networks.
الشبكة الافتراضية الخاصة تُشفّر كامل اتصالك بالإنترنت، مما يحمي كل الحركة على الشبكات العامة أو غير الموثوقة.
📡
Dynamic ARP Inspection
فحص ARP الديناميكي
Network switches can verify ARP packets against a trusted DHCP binding table, blocking spoofed ARP replies.
مبدّلات الشبكة يمكنها التحقق من حزم ARP مقابل جدول ربط DHCP الموثوق، مما يمنع ردود ARP المزيفة.
📜
Certificate Pinning
تثبيت الشهادة
Applications can "pin" the expected server certificate, rejecting any certificate not matching — even if it's signed by a CA.
التطبيقات يمكنها "تثبيت" شهادة الخادم المتوقعة، ورفض أي شهادة لا تطابقها — حتى لو كانت موقّعة من CA.
⚓
HSTS (HTTP Strict Transport Security)
أمان نقل HTTP الصارم
HSTS tells browsers to only connect via HTTPS, preventing downgrade attacks that force HTTP connections.
HSTS يخبر المتصفحات بالاتصال عبر HTTPS فقط، مما يمنع هجمات التخفيض التي تفرض اتصالات HTTP.
🏠
Avoid Public Wi-Fi
تجنب Wi-Fi العام
Public networks are prime hunting grounds for MITM attackers. Use mobile data or a VPN when on public networks.
الشبكات العامة هي أرض خصبة لمهاجمي MITM. استخدم البيانات الجوال أو VPN عند الاتصال بالشبكات العامة.

Learning Objectives

الأهداف التعليمية
🇬🇧 Learning Goals
  • Understand how ARP spoofing enables MITM positioning
  • Capture and analyze unencrypted HTTP and SMTP traffic
  • Distinguish between encrypted vs unencrypted protocols
  • Modify intercepted data and understand the impact
  • Apply countermeasures: TLS, VPN, ARP inspection
🇸🇦 الأهداف التعليمية
  • فهم كيف يُمكّن تزوير ARP من موضع MITM
  • التقاط وتحليل حركة HTTP وSMTP غير المشفرة
  • التمييز بين البروتوكولات المشفرة وغير المشفرة
  • تعديل البيانات المعترضة وفهم التأثير
  • تطبيق التدابير المضادة: TLS، VPN، فحص ARP
